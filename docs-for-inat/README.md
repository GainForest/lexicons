# docs-for-inat

A tiny zero-dependency Node app for the iNaturalist architecture briefing.

It does two things:

1. Renders `architecture.md` as a styled documentation page at `/`.
2. Serves the raw markdown file at `/architecture.md`.

## Run locally

```bash
npm start
```

Open <http://localhost:3000> for the rendered page or <http://localhost:3000/architecture.md> for the raw markdown.

## Test

```bash
npm test
```
